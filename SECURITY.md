# Security

Please report security problems privately, not in a public issue.

- Preferred: [report a vulnerability](https://github.com/librarycottonwood/cottonwood-library-assistant/security/advisories/new) through GitHub.
- Or email the library at cottonlib@shasta.com with "Website security" in the subject.

Include what you found, where (page, file or URL), and how to reproduce it. Please don't access visitors' or donors' data, change the website, or run load or denial-of-service tests.

The library is small and mostly volunteer-supported, so replies may take a few days. There is no bug bounty.

## Scope

- The website at https://cottonwood-library.pages.dev/ and cottonwoodcommunitylibrary.com
- The code in this repository, including the Cloudflare Workers in `cms-publisher/` and `connector/` and the GitHub workflows

Givebutter, Sanity, Cloudflare, Google and OpenAI are separate services; report problems in them to those companies.
