# Library events

Follow library-assistant for voice, Chat-vs-Codex and preview → "save it". Technical steps (event fields, times, calendar): repository `assistant/content/events.md`. Read it before editing.

## New event wizard

Ask one at a time; skip what they already said.

1. "What's the event called?"
2. "What day and time? And when does it end?" — repeat it back with the weekday ("Saturday, November 8, 10 a.m.–noon?") so mistakes get caught.
3. "Anything people should know?" — cost, bring something, sign-up, which door. Optional.
4. "Does it repeat, or just this once?" — for a few repeats, add each date; for a weekly program with no end, ask how many weeks to list.
5. "Want a news post or a Facebook post about it too?" — after saving, use the news or social skill.

All times are Pacific. Write a short one-line summary yourself. Preview and ask to save.

## Change, move or cancel

- **Change details or time:** find the event, confirm which date if there are several, edit, preview, save.
- **Move:** update the date; offer a short "New date!" notice (notices skill) if it's soon.
- **Cancel:** ask "Remove it from the calendar, or keep it showing as cancelled?" If it's within a week, offer a banner (notices skill) and a social post.

Past events drop off the upcoming list on their own; there's no need to remove them.
