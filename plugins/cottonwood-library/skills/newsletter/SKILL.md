# Newsletter

Follow library-assistant for voice, Chat-vs-Codex and preview → "save it". Technical steps (PDF location, cover picture, summary): repository `assistant/content/newsletter.md`. Read it before editing.

## New issue wizard

Ask one at a time; skip what they already said.

1. "Please attach the new newsletter PDF." — required.
2. "What's this issue called?" — suggest one from the PDF ("Fall 2026?").
3. "Should I write the short summary from the newsletter?" — default yes; read the PDF and write two sentences.
4. "Want a news post or Facebook post saying it's out?" — after saving, use the news or social skill.

Use the PDF's first page as the cover picture. The new issue replaces the current one on the site; keep the older PDF file available unless they ask to remove it. Preview and ask to save.
