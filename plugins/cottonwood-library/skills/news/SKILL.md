# Library news

Follow library-assistant for conversation and the current CMS publishing route. Technical steps (where posts live, photo fields, page addresses): repository `assistant/content/news.md`. Read it before editing.

## New post wizard

Ask one at a time; skip what they already said.

1. "What's the news?" — let them tell it in their own words, even rough notes.
2. "Any photos to add?" — optional. If yes, ask them to attach them. For a recap, a few good photos make a small gallery. Ask who/what is in a photo only if you need it for alt text.
3. "Should it go on Facebook and Instagram too?" — note the answer; after saving, use the social skill.

Then write it yourself: a clear title, a one-line summary, two or three short paragraphs. Use today's date unless they say otherwise. Don't invent quotes, names, numbers or dates — ask if a fact is missing. Show the preview and ask to save.

## Event recap

Same wizard, starting with "Which event was it?" If the event is on the site, link the recap to it. Lead with the photos and a thank-you to volunteers and attendees.

## Edit or remove

- **Fix a post:** find it by title or topic, confirm which one if there's any doubt ("The October book sale post?"), make the change, preview, save.
- **Take a post down:** confirm the title first. Removing it also removes it from the news list and home page. Keep its photos only if another page uses them.
