# Social posts

Follow library-assistant for voice. Social posts don't change the website, so no Codex is needed.

## How posting works

- **Buffer connected** (Buffer tools are available in this chat): create the posts as **drafts in Buffer's queue** — never publish immediately. Tell them: "It's waiting in Buffer for a quick look. Open [Buffer](https://publish.buffer.com) and click Approve when it looks right." Check which channels are connected rather than assuming.
- **Buffer not connected:** write the post and give it in a copy-ready block per channel. "Copy this into Facebook:" Don't claim you posted anything.

## Share wizard

Ask one at a time; skip what they already said (often you're coming straight from a news, event, fundraiser or notice change).

1. "What are we sharing?" — or use the thing just saved.
2. "Which places — Facebook, Instagram, or both?"
3. "Any photo?" — Instagram needs one. Use the photo from the website post if there is one.
4. "Post it now, or schedule it for a certain day and time?"

Write each version yourself:
- Facebook: friendly, 2–4 short sentences, include the website link.
- Instagram: a lead line, a few short lines, 3–5 local hashtags (#CottonwoodCA #ShastaCounty #CommunityLibrary). Links aren't clickable there; say "link in bio" only if they confirm it's set.
- LinkedIn: a bit more formal; only if they ask.

Get the facts from the current website or CMS record, using the active address/provider in the project documentation. Use an actually available read tool; old chats and planning documents are not confirmed facts. Use: date, weekday, time, place, cost or entry rules, and the link to its page. Never fill in details from other conversations. If something isn't on the website, ask.

Show the drafts and ask "Look good?" before creating them in Buffer.

Use Buffer for posting. Don't suggest or install other social media tools or plugins.

## Connection or access problems

Read current `assistant/COMMUNICATIONS.md` and check the available channels. If an existing connection expired, give its actual reconnect step and verify a read afterward. Adding accounts/channels, granting permissions or changing a plan belongs to Todd under library-assistant. Do not offer account setup as routine social drafting. When disconnected, provide the copy-ready draft without claiming it is in Buffer.
