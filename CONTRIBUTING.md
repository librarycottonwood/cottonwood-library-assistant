# Contributing

This repository runs one library's website, so outside pull requests aren't accepted. Changes come from the library through its assistant (see [README.md](README.md)).

- Spotted a mistake on the website (wrong hours, a broken link)? Email the library at cottonlib@shasta.com.
- Found a security problem? See [SECURITY.md](SECURITY.md).

You're welcome to read, fork and reuse the code under the [MIT License](LICENSE). The library's name, logo, photographs and written content are not covered by it.
