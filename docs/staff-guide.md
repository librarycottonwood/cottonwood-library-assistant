# Updating the library website with Claude

> **Not in use yet.** Staff use ChatGPT to update the website. This guide is for a possible later move to Claude.

A one-page guide for library staff and board volunteers.

## Getting started

1. Go to https://claude.ai/code and sign in with the library's Claude account.
2. Pick the repository **cottonwood-library-assistant** and the **Cottonwood Library** environment. Start a new session (not a "Project").
3. Type what you want in your own words.

## Things you can ask

- "Add a news post about the book sale. Here are some photos."
- "Add an event: Story Time, Saturday November 14, 10 to 11 a.m."
- "We're closed Thanksgiving Thursday and Friday. Put up a banner."
- "Start a fundraiser for the new roof." / "End the roof fundraiser."
- "Here's the winter newsletter PDF. Put it on the website."
- "Write a Facebook post about Story Time."
- "Take down the October book sale post."
- "How many people visited the website last month?"
- "Every Monday, tell me what events are coming up."

Claude asks one question at a time. If you don't know an answer, say so.

## How saving works

1. Claude makes the change and builds a **preview**: a private copy of the website with your change.
2. Claude sends you the preview link. Look at it.
3. Claude asks **"Ready to save?"** Say **yes** only when it looks right. Anything else ("change the time first", "not yet") is not a yes.
4. Claude asks permission on screen to save. Click **Allow** (or Yes).
5. About 5-10 minutes later the change is on the live website. Claude checks it and tells you.

Nothing goes live without your yes. If you change your mind before saying yes, just say "cancel". Claude puts the old version back so it can't go live with someone else's change.

## Good to know

- Facebook posts go into **Buffer** as drafts. Open https://publish.buffer.com and click Approve to post them.
- Claude can't send the email newsletter. It writes the email; you paste it into Givebutter.
- If Claude says a safety check stopped it, that's on purpose. Ask Todd Haines (toddhaines7@gmail.com) if you think it's wrong.
- Never paste passwords or codes into the chat.
- Only share photos the library has permission to use.

## When something goes wrong

- **The preview looks wrong:** tell Claude what's wrong. It fixes and makes a new preview.
- **The live site didn't change:** ask "Where is my change?"
- **Want to undo a saved change:** ask "Undo the last change." It goes through the same preview and yes.
- **Claude is stuck or confused:** start a new session and ask again in one sentence.
- **Still stuck:** check the GitHub issue titled "Website needs attention", or contact Todd Haines, the board admin, at toddhaines7@gmail.com.

You can also edit words and photos directly in the website editor: https://cottonwood-community-library.sanity.studio/ Publishing there saves the words, but the live website only updates after the preview-and-approve step. If unsure, ask Claude "Is my editor change live?"
