# Homepage heading comparison

The preview offers a handwritten word, a leaf accent, and the existing plain heading. The complete heading still comes from the CMS. These are design comparisons, not an approved final treatment.

- **Handwriting:** [Caveat](https://fonts.google.com/specimen/Caveat), Copyright 2014 The Caveat Project Authors, from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/caveat). The locally hosted variable WOFF2 is subset to Latin and punctuation; its SIL Open Font License is retained in `src/assets/fonts/Caveat-OFL.txt`.
- **Leaves:** original SVG geometry in `src/assets/decorations/hero-leaves.svg`, using the existing indigo, green and pale-indigo tokens.

The temporary picker is available only on local or immutable preview hosts with `?hero-style=handwritten`, `?hero-style=leaves`, or `?hero-style=plain`. The default heading remains plain. Remove the picker and unused treatments once a direction is chosen.
