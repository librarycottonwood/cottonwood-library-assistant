# Hero marker artwork

`src/assets/decorations/hero-marker.svg` adapts **Underline 7** from [Highlights by Outdraw Design](https://www.highlights.design/elements), offered under [CC0](https://www.highlights.design/).

Original SVG: https://uploads-ssl.webflow.com/618ce467f09b34ebf2fdf6be/62779ade66524281390c19f9_Underline%207.svg

The path is unchanged. Its fill uses `currentColor`, its aspect ratio stretches to the heading, and it is decorative. The preview compares pale yellow and lavender applications of that shape with a simple green polygon.
