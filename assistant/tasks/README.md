# Scheduled task prompts

Canonical copies of the prompts behind the ChatGPT Scheduled tasks in the
library account (@cottonwoodlibrary). ChatGPT keeps no history of task edits
and anyone signed in can change them, so this folder is the source of truth.

| ChatGPT task | Prompt file | Schedule | Executor |
| --- | --- | --- | --- |
| Weekly Maintenance Check | `weekly-maintenance.md` | Monday 14:00 America/Los_Angeles | Cloud (task 6ac5a460da40819092fe6b5e6403c3cd) |

When you change a prompt: edit the file here first, then paste it into the
task in ChatGPT. If a task drifts or is deleted, recreate it from the file
with the same schedule. Pinned chats in the sidebar are not tasks and have no
prompt to keep here.
